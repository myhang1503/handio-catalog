# HANDIO catalog

Astro site for HANDIO macrame, deployed on Cloudflare. Photos live on the R2 CDN (`cdn.handiomacrame.com`).

- Products: `src/content/products/*.md`
- Journal posts: `src/content/journal/*.md`
- Brand details and CDN paths: `src/config.ts`

```sh
npm run dev      # local dev server
npm run build    # production build into dist/
```
